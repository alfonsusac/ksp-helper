# How to Take Picture of Planets

- Get CKAN, Get Distant Object Enhancement
- Set Skybox brightness to 0
- Go to KSP, zoom out, and decrease Fov to lowest (option + scroll)
- Go to Planet, change MNA to find perfect angle, change Semi-Major Axis to fit planet to screen
- Save Image, go to Photoshop/Photopea
- Select Black Background, Expand Selection by 1px
- Delete Background, Trip Image to Fit by removing transparency
- Save to /public/...package name.../planets/(planet-name)-hd.png
