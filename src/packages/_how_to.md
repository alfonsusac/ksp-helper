# How to Take Picture of Planets and Satellites

- Get CKAN and install the required mods.

Required Mods:
- Distant Object Enhancvement
- Texture Replacer
- Time Control
- HyperEdit (Optional)

- Make 1080x1080 white square and save with the following filenames:
  - GalaxyTex_PositiveX.png
  - GalaxyTex_NegativeX.png
  - GalaxyTex_PositiveY.png
  - GalaxyTex_NegativeY.png
  - GalaxyTex_PositiveZ.png
  - GalaxyTex_NegativeZ.png
- Save it to (ksp instance path)/GameData/TextureReplacer/Default

- Go to KSP, open cheat mode and disable destruction/heat/temp/drag/ec... 
- zoom out, and decrease Fov to lowest (option + scroll)
- Go to Planet, change MNA to find perfect angle, change Semi-Major Axis to fit planet to screen. Use HyperEdit to change orbit
- Stop the time
- Set Skybox brightness to 0% (for Black BG) 
- Screenshot, copy and paste to ksp-tools.alfon.dev/alpha-matte-bg-remover
- Set Skybox brigthness to 100% (for white BG)
- Screenshot, copy and paste to `ksp-tools.alfon.dev/alpha-matte-bg-remover`
- Crop the UI and trim the background using `ksp-tools.alfon.dev/planet-cropper`
- Save to /public/...package name.../planets/(planet-name)-hd.png

If its a star with flare/scatterer, Screenshot it as far as you can to the point 
the scatterer is contained within the screen, and paste it to `ksp-tools.alfon.dev/screen-to-transparent`
