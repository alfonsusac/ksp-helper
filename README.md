This is a website that contains KSP-related calculator that I built.

Calculators:
- Calculate maximum range of antennas between two points
- Get the ideal height for a relay network

Stack: 
- Next.js for Front end and Back end
- Tailwindcss for design systems
- BaseUI for headless components

Features: 
- Light and Dark Mode
- Settings and Mod compatibility
- Share URL and persist data between page loads.

### Development

I use `pnpm`. So just type `pnpm i` then `pnpm dev` and open `localhost:3000` to preview development build while you change the code.

Contributions and feedbacks are welcome!
